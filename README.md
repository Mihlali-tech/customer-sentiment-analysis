# 📊 E-Commerce Customer Sentiment Analysis & Insights Dashboard

An end-to-end Data Science and Natural Language Processing (NLP) project that cleans raw customer reviews, performs automated sentiment analysis using TextBlob, uncovers business insights across product categories and customer segments, and presents findings through an interactive Streamlit dashboard.

---

## 🚀 Project Overview
In e-commerce, understanding customer feedback is critical for product development and retention. This project processes 300 customer reviews, classifies sentiment polarity (Positive, Neutral, Negative), evaluates category performance, and delivers actionable strategic recommendations.
